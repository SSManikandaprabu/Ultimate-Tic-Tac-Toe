# Ultimate Tic-Tac-Toe

A modern Tic-Tac-Toe web game featuring classic 3x3 play, expanded game modes, and intelligent AI opponent capabilities.

## Features

- Classic 3x3 grid and Ultimate Tic-Tac-Toe game mechanics
- Multiple game modes: 2-Player local pass-and-play and Single Player vs. AI
- Intelligent AI opponent with minimax decision-making logic
- Interactive turn indicators, winning line animations, and draw detection
- Match score counter tracking wins, losses, and ties with LocalStorage persistence
- Clean responsive layout with instant game reset

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla ES6)
- LocalStorage API

## Installation & Setup

This is a standalone, client-side web application. No build systems or backend servers are required.

1. **Clone the repository:**
   `ash
   git clone https://github.com/SSManikandaprabu/Ultimate-Tic-Tac-Toe.git
   cd Ultimate-Tic-Tac-Toe
   `

2. **Run the application:**
   - **Direct Browser Launch**: Double-click index.html to open it directly in any modern web browser.
   - **Or via Local HTTP Server**:
     `ash
     python -m http.server 8000
     `
     Then open [http://localhost:8000](http://localhost:8000) in your browser.

## Usage

1. Launch index.html in your browser.
2. Select your game/quiz settings and start playing.
3. High scores and game records are saved locally in your browser's LocalStorage.
